\textbf{RTSpMSpM: Harnessing Ray Tracing for Efficient Sparse Matrix Computations} \\
\hspace*{15pt}Lab: ESCAL, Riverside \hfill September 2023 – Present
\begin{itemize}
    \item Designed the algorithm that maps the sparse matrix multiplications (SpMSpM) into ray tracing problems to enable the use of ray tracing accelerators in solving SpMSpM.
    \item Developed a library that realized the proposed algorithm using OptiX and CUDA to achieve 1.85× speedup over cuSPARSE on NVIDIA’s RT Cores.
    \item Integrated the developed library into a graph neural network training framework using CUDA and Python to achieve more than 3× speedup on NVIDIA RTX 4090 GPUs.
  \end{itemize}
